How It Works

The system processes the input through several stages.

Input

Text, image or PDF is provided for analysis.

Extraction

OCR or PDF extraction obtains the article text.

NLP

Text is cleaned, normalized and transformed for the selected model.

Prediction

The selected model predicts whether the article is Real or Fake.

Model Comparison

Two different approaches were implemented and evaluated.

TF-IDF + Logistic Regression

A traditional NLP approach using TF-IDF features and Logistic Regression classification.

99.10% Test Accuracy
TF-IDF Scikit-learn Logistic Regression

LSTM Neural Network

A deep learning approach using tokenized text, embeddings and an LSTM sequence model converted to TFLite/LiteRT.

93.34% Test Accuracy
LSTM TFLite LiteRT

About the Project

Built as an academic NLP and machine learning project.

Project Objective

The purpose of this project is to explore how Natural Language Processing, machine learning, deep learning and Big Data techniques can be combined to analyze news content.

The application supports direct text analysis as well as text extraction from images and PDF documents.

Technologies Used

Python NLTK Scikit-learn NumPy TensorFlow TFLite LiteRT LSTM PySpark Flask Gunicorn Tesseract OCR PyMuPDF ReportLab

Deployment

The application supports different model configurations depending on the environment.

Local Development Flask development server with both TF-IDF + Logistic Regression and LSTM TFLite/LiteRT prediction available.
Render Cloud Deployment Gunicorn production server with TF-IDF + Logistic Regression prediction. LSTM is disabled on the cloud server to reduce memory usage.
Note: The result is a machine-learning prediction based on patterns learned from the training dataset. It should not be treated as guaranteed factual verification.
