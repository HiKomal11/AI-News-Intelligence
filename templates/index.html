How It Works

The system processes the input through several stages.

Input

Text, image or PDF is provided for analysis.

Extraction

OCR or PDF extraction obtains the article text.

NLP

Text is cleaned, tokenized and transformed.

Prediction

The selected model predicts the news class.

Model Comparison

Two different approaches were implemented and evaluated.

TF-IDF + Logistic Regression

A traditional NLP approach using TF-IDF features and Logistic Regression classification.

99.10% Test Accuracy

LSTM Neural Network

A deep learning approach using tokenized text, embeddings and an LSTM sequence model.

93.34% Test Accuracy

About the Project

Built as an academic NLP and machine learning project.

Project Objective

The purpose of this project is to explore how Natural Language Processing, machine learning, deep learning and Big Data techniques can be combined to analyze news content.
